
# Mi mundo de mascotas

## Descripción
Aplicación web sencilla desarrollada como actividad de nivelación de la Unidad 1 de Desarrollo Móvil Integral.

## Objetivo
Demostrar el proceso de desarrollo de software mediante una interfaz con un título, una imagen y un botón que muestra un mensaje.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Git y GitHub

## Modelo de desarrollo
Scrum, utilizado para organizar las responsabilidades y actividades del equipo.

## Integrantes
- Integrante 1: Product Owner y desarrollador.
- Integrante 2: Scrum Master y desarrollador.

## Funcionalidades
- Mostrar el título de la aplicación.
- Presentar una imagen.
- Mostrar un mensaje al presionar el botón.
